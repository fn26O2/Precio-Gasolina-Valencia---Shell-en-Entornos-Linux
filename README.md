Sistema automatizado en Bash programado mediante `cron` para la descarga, procesamiento y generación de informes periódicos (TXT y HTML).

## Estructura del Proyecto
- `datasets/`: Registro local de datos descargados.
- `informes/`: Informes generados en `.txt` y `.html`.
- `planificacion/`: Configuración del cron (`crontab.txt`).
- `script_analisis.sh`: Script principal de automatización.
- `log.txt`: Registro de ejecución con marcas de tiempo.
